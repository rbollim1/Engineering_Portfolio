Computer Vision · E27 Final Project

MNIST Digit Classification:
Single-Layer vs. Convolutional Neural Network

Comparative study of optimizer performance on MNIST across two network architectures (TensorFlow / Keras)

Deep Learning Computer Vision Python TensorFlow CNN

Summary

This project implements and compares two neural network architectures for handwritten digit classification on MNIST: a flat single-layer softmax classifier and a multi-layer convolutional neural network. The study evaluates the effect of different optimizers on training dynamics, convergence speed, and final accuracy, with results visualized through training curves and confusion matrices.

  • Implemented a single-layer (784→10 softmax) baseline classifier
  • Built a 3-block CNN (Conv2D → MaxPool → Conv2D → MaxPool → Conv2D → Dense)
  • Compared SGD, Adam, and RMSProp across both architectures
  • Analyzed per-class error via confusion matrices and classification reports

Architectures

Method 1 — Single-layer network

A minimal baseline: each 28×28 image is flattened to a 784-dim vector and passed directly to a 10-unit softmax output layer. No hidden layers. Trained with sparse categorical cross-entropy and multiple optimizers to isolate the effect of optimization strategy on a linear classifier. 

Input (784) → Dense(10, softmax)

Method 2 — Convolutional neural network

A deeper architecture that preserves spatial structure through three convolutional blocks before a fully connected head. The network learns hierarchical features — edges, curves, and digit-level patterns — before classifying. 

Input (28×28×1)
  → Conv2D(32, 3×3) + ReLU → MaxPool(2×2)
  → Conv2D(64, 3×3) + ReLU → MaxPool(2×2)
  → Conv2D(64, 3×3) + ReLU
  → Flatten → Dense(64, ReLU) → Dense(10, softmax)

Optimizer Comparison

Both architectures were trained under identical conditions with three optimizers — SGD, Adam, and RMSProp — to evaluate their effect on convergence speed and final test accuracy. Training and validation accuracy were tracked per epoch, and confusion matrices were generated on the held-out test set for each configuration.

Key findings:

  • The CNN substantially outperformed the single-layer model across all optimizers
  • Adaptive optimizers (Adam, RMSProp) converged faster than SGD in both architectures
  • Confusion matrices revealed consistent error patterns on visually similar digit pairs (e.g., 4/9, 3/5)

Hypothesis Testing

Beyond reporting accuracy, the project formulated and tested explicit hypotheses about optimizer behavior — predicting convergence speed rankings before training and validating them against empirical results. This structured approach to experimental design was noted in grader feedback.
